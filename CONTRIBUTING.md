# Contributing to OpenSprite

Thank you for your interest in contributing to OpenSprite! We welcome your ideas, feedback, and improvements.

## How to Contribute

- **Issues:** If you have suggestions, feature requests, or find bugs, please open an issue describing the problem or idea.
- **Pull Requests:** To propose changes, fork the repository, make your changes, and submit a pull request. Please include a clear description of your changes and the motivation behind them.

## Discussion

We encourage open discussion via issues before starting large or complex changes to ensure alignment with the project goals.

## Code and Tests

At this early stage, there may not be an established build or test suite. Contributions focused on documentation, ideas, and planning are especially valuable now.

## Thank You

Your contributions help shape OpenSprite into a valuable tool for indie developers. We appreciate your time and effort!
