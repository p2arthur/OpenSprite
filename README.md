# OpenSprite

A simple local asset organizer for indie game developers to find sprites, textures, models, and audio, and track their sources and licenses.

---

## Purpose

OpenSprite is designed to help indie developers manage their game assets efficiently. It focuses on providing solo indie developers, small teams, hobbyists, and game jam participants with a straightforward way to organize their asset collections and keep track of sources and licenses.

## Audience

- Solo indie game developers
- Small game development teams
- Hobbyists creating games
- Participants in game jams

## Current Status

This repository currently contains the initial project scaffolding and documentation. Implementation and usage instructions will be developed and added as the project progresses.
